# Android-приложение дашборда

Две версии из одного кода: **QMT Склад** и **Arlan Склад**. Приложение открывает сайт дашборда,
поэтому обновления сайта видны в нём сразу, без переустановки.

Скачать (последняя сборка):
- QMT: https://github.com/kroxk910-ctrl/saiman-dashboard/releases/download/android/QMT-Sklad.apk
- Arlan: https://github.com/kroxk910-ctrl/saiman-dashboard/releases/download/android/Arlan-Sklad.apk

Сборку делает GitHub Actions (`.github/workflows/android.yml`) при каждом изменении в папке `android/`.
APK подписывается ключом из секретов репозитория `ANDROID_KEYSTORE` и `ANDROID_KEYSTORE_PASSWORD` —
не меняйте и не удаляйте их, иначе новые версии не встанут поверх установленных.

Что умеет приложение сверх сайта:
- уведомления в шторке телефона, когда приложение свёрнуто (нажатие открывает нужную вкладку);
- работа в фоне — тихий значок в шторке, чтобы телефон не «усыплял» приложение (выключается в настройках уведомлений дашборда);
- загрузка PDF с телефона, кнопка «Назад» закрывает открытые окна;
- ссылки на Telegram/WhatsApp открываются в своих приложениях.
